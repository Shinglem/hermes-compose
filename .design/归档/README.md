## 归档纪律

1. **移进来就不再改**（除非修正事实错误并注明日期）。
2. **移动时在 `../README.md` 的索引里删掉对应行**，避免出现「文档存在但没人知道」。
3. **提炼优先**：归档前先把「仍然成立的结论」写进常设文档 —— 归档是**备份**，不是替代。
