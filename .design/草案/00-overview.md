# 00 · 项目概览

## 一句话

用 Kotlin + Compose Multiplatform 重写 Hermes 桌面客户端，**后端完全不动**，目标平台 Windows 优先。

## 为什么要重写

| 动机 | 说明 |
|---|---|
| 体积与启动 | Electron 运行时 + React 生态（生产代码 ≈ 45 万行）带来体积与冷启动成本 |
| 原生手感 | 滚动、输入法、快捷键、窗口管理在 Web 壳里始终隔一层 |
| 可控性 | 不需要跟随上游 React 生态的依赖升级节奏 |
| 精简 | 官方客户端里约一半能力（插件市场、文件树、群聊、远程屏幕）本项目不用 |

## 本期范围（P0–P5）

```
┌────┬──────────────────┬────────────────────────────────┐
│ 头 │  会话列表         │  对话 + 终端                    │
│ 像 │  （置顶/时间分组） │                                │
│ 条 │                  │                                │
├────┴──────────────────┴────────────────────────────────┤
│ 状态条                                                  │
└────────────────────────────────────────────────────────┘
```

1. **会话主窗口**：左窄 rail（profile 切换）+ 中栏会话列表 + 右栏对话与终端 + 底部状态条。
2. **对话**：流式 Markdown 渲染、代码高亮、工具调用卡片、逐条复制/引用。
3. **输入框**：Markdown 源码输入、chip（@ 引用）、@ 补全、粘贴图片、Enter 发送。
4. **能力页**：中栏三分类（技能与工具 / 消息平台 / 定时任务），右栏对应设置页。
5. **终端**：BossTerm，默认收起为标题条。
6. **设置**：模型、外链编辑器、代理、外观。

## 后续（不在本期）

- IM 风格的独立聊天窗口（从主窗口按钮弹出，共享同一连接）
- 群聊 / 多 bot 协作
- 插件体系
- 远程屏幕

## 与官方客户端的关系

- **不 fork、不 vendored**：这是一个独立仓库，只消费 Hermes 后端的公开契约。
- 契约以 `C:\ai\hermes\app\apps\shared\src\gateway-contract.generated.ts` 为准（由 Python 单源生成）。
- 官方客户端继续存在；本项目是并行的替代前端，不是替代品发布。

## 成功判据（一句话版）

能完成"打开 → 选会话 → 提问 → 看着流式回答 → 用终端验证 → 改配置"这五步，不怀念 Electron 版。
量化版本见 `05-acceptance.md`。
