# 04 · UI 规格

> 采用 Material 3 **canonical list-detail** 布局（`ListDetailPaneScaffold`）。
> 视觉遵循 M3 原生默认值（配色、密度、字号），**不追求与官方客户端 1:1**。
> 配色可在 `options.ui.style` 里换（material / paper / ocean / sage / plum / amber），
> 每套都只是替换 M3 的**语义角色**（`ColorScheme`），间距 / 圆角 / 字号仍是 M3 默认值 —— 见 ADR-055。

**视觉稿**：[`../详细设计/UI设计/index.html`](../详细设计/UI设计/index.html)（浏览器直接打开，7 个视图）。
本文定布局口径与交互规则，视觉稿定配色与组件形态；两者冲突时以本文为准并修视觉稿。

> **视觉稿不严格遵循 M3，也不是像素基准。** 实现一律用 **Material 3 + Compose 原生组件**，
> 间距、圆角、密度**允许与稿子不同**；不要为对齐稿子自绘控件或写死尺寸。
> 差异判定顺序：**功能对等 > 原生观感 > 视觉接近**。

## 1. 整体结构

```
┌──────┬────────────────────┬──────────────────────────────────────────┐
│      │                    │  顶栏：会话标题 · 模型 · 操作              │
│ rail │  中栏（list pane）  ├──────────────────────────────────────────┤
│ 64dp │  约 360dp          │                                          │
│      │                    │  右栏（detail pane）                      │
│ 头像 │  搜索              │                                          │
│ 竖列 │  ────────          │  对话                                     │
│      │  ★ 置顶会话         │                                          │
│      │  ────────          │                                          │
│      │  今天               │                                          │
│      │   会话…            ├──────────────────────────────────────────┤
│      │  昨天               │  composer                                │
│      │   会话…            ├──────────────────────────────────────────┤
│      │  更早               │  ▸ 终端（收起时仅此一条 32dp）             │
│      │                    │                                          │
│ ⚙    │  ＋ 新建会话         │                                          │
├──────┴────────────────────┴──────────────────────────────────────────┤
│ 状态条：profile · 连接状态 · 模型 · 用量 · 终端状态                    │
└──────────────────────────────────────────────────────────────────────┘
```

- rail 在 scaffold **之外**（它是导航，不是 pane）。
- 底部状态条通过 `Scaffold(bottomBar = …)` 实现，通栏。
- 窄窗口（< 840dp）：scaffold 自动退化为"单栏 + 返回"，这是它的原生行为。

## 2. 左 rail（64dp）

| 位置 | 内容 |
|---|---|
| 顶部第 1 项 | **default / 全局**（固定图形，不用首字母） |
| 依次 | 每个 profile 一个圆形头像（36–40dp），首字母 + 固定色 |
| 选中态 | M3 `secondaryContainer` 圆角方块衬底 + 头像 |
| 状态点 | 右下角小圆点：该 profile 有运行中任务时显示 |
| 底部 | **两个平级入口**：`能力`（宫格）与 `设置`（齿轮）；各自有选中态 |

交互：

- 左键：切换 profile 或进入「能力」/「设置」。**点任一 profile 头像 = 回该档案的会话列表**。
- 右键：编辑资料 / 复制配置 / 删除。
- 头像滚动：profile 多于可视高度时 rail 内部滚动（不撑高窗口）。
- 「能力」是导航目的地而不是模式开关：进入后该项保持「能力」标签与图标，不会变成「会话」按钮（ADR-048）。

## 3. 会话模式

### 3.1 中栏（list pane）

| 区块 | 内容 |
|---|---|
| 顶部 | 搜索框（过滤标题） |
| 置顶区 | 置顶会话，独立一段、无标题 |
| 分组区 | 今天 / 昨天 / 7 天内 / 更早，每组标题可点击折叠 |
| 行 | 标题（单行省略）+ 右侧时间 + 未读点；hover 显示 `⋯` |
| 底部固定 | `＋ 新建会话` |
| 空状态 | 提示文案 + 新建按钮 |

- 分组标题**不吸顶**（CMP #3016）。
- 折叠状态持久化到 `groups.collapsed`。
- 行操作：重命名 / 置顶 / 删除。

### 3.2 右栏（detail pane）

纵向三段（不滚动切换，固定分割）：

```
┌──────────────────────────────┐
│ 顶栏：标题（可重命名）· 模型 · ⋯ │  48dp
├──────────────────────────────┤
│ 消息列表（LazyColumn，流式吸底） │  weight 1
│                              │
├──────────────────────────────┤
│ composer（自动高度 1–10 行）    │  auto
├──────────────────────────────┤
│ ▸ 终端（收起 32dp / 展开 40%）  │  toggle
└──────────────────────────────┘
```

**消息样式**：全宽段落式（不做左右气泡）。用户消息用浅色容器块区分。
工具调用以"通用卡片"呈现：标题 + 状态（运行中/成功/失败）+ 折叠参数 + 结果区。

**composer 底部操作行**（输入框独占上面一行，长文本换行不会把按钮挤走）：

```
│ 输入框（BasicTextField，自动高度 1–10 行）              │
│ 📎   [deepseek-v4.1-flash ⌄]  [Med ⌄]          ⏹ / ➤  │  28–34dp
```

- 模型 pill：按 provider 分组的目录，当前项打勾；切完等 `session.info` 刷新（ADR-038）
- 推理强度 pill：`Off/Min/Low/Med/High/XHigh/Max`；模型不支持推理时整控件隐藏
- 「新建会话」按钮在**中栏列表底部**常驻，不在搜索行右侧

**消息操作**（hover 显示）：复制整条 / 引用（把文本带入 composer）/ 复制代码块。
跨消息连选不可用（机制限制），见 `05-acceptance.md`。

### 3.3 终端面板

- 收起态：32dp 标题条 = `终端` + 运行状态点 + 展开箭头。
- 展开态：向上占右栏 40%，可拖拽调整；内含 BossTerm。
- 快捷键：`Ctrl+``（反引号）切换。
- 焦点规则：点进终端后 `Ctrl+C` / `Ctrl+W` / `Tab` 归终端；点出恢复全局。

## 4. 能力模式

点 rail 的「能力」按钮进入能力模式。**中栏换成 3 个分类，右栏换成对应设置页。**
（「能力」是导航目的地，进去后不会变成「会话」按钮 —— 回会话点 profile 头像。）

```
┌──────┬────────────────────┬──────────────────────────────────────────┐
│ rail │  能力               │  技能与工具                                │
│      │  ────────          │                                          │
│      │  ▸ 技能与工具  ◀    │  搜索 · [技能 | 工具集]                   │
│      │  ▸ 消息平台         │  ─────────────────────                   │
│      │  ▸ 定时任务         │  技能列表（名称/描述/来源/开关）           │
└──────┴────────────────────┴──────────────────────────────────────────┘
```

- 中栏：**固定三项**，但用"分类配置表 + LazyColumn"渲染（将来加"插件/MCP"只改表）。
- 右栏：选中分类的完整设置页。
- 能力模式下**终端不显示**（属于会话上下文）；切回会话模式恢复原状态。
- 会话 ↔ 能力切换时，**会话状态保留在后台**，切回不回到列表。

### 4.1 技能与工具

| 区域 | 内容 |
|---|---|
| 顶部 | 搜索框 + `[技能 | 工具集 | 发现]` 分段按钮 |
| 技能列表 | 名称 + 一行描述 + 来源 chip（内置/用户/插件）+ `Switch` |
| 技能展开 | 完整 `SKILL.md`，用 Markdown 渲染器 |
| 工具集 | 按工具集分组（名称 + 工具数 + `Switch`），展开看工具清单 |
| 发现（技能库） | 分类 chip 行（全部 + 各分类带数量，横向滚动）+ 条目列表（名称 + 分类/来源 chip + 描述）；展开看 repo / identifier / tags + `[安装]`。已安装的条目不显示安装按钮 |

数据：`GET /api/skills`、`/api/skills/content?name=`、`/api/toolsets`、
`GET /api/skills/hub/official`（发现页，本地扫描 152 项）、`POST /api/skills/hub/install`。

> 发现页只用后端**本地扫描**的官方可选技能库。联网多源搜索（`hub/sources` / `hub/search` / `hub/preview`）
> 与官方桌面端的 64 MB CDN 快照本机不可用，见 ADR-049。

### 4.2 消息平台

| 区域 | 内容 |
|---|---|
| 卡片列表 | Telegram / 企业微信 / 飞书 / Slack / Discord / Email |
| 卡片头 | 图标 + 名称 + 状态 chip（已连接 / 未配置 / 错误）+ `Switch` |
| 卡片体（展开） | token / webhook / 白名单 + `[测试连接]` + `[保存]` |

### 4.3 定时任务

| 区域 | 内容 |
|---|---|
| 顶部 | `[+ 新建]` + 搜索 |
| 列表行 | 名称 + cron 表达式（附中文概览）+ 下次运行时间 + 上次结果 chip + `Switch` |
| 编辑 | 名称 / 表达式 / prompt / 模型 / 启用 + `[立即运行]` + 最近运行历史 |

数据：`/api/cron/*`（列表 / 创建 / 更新 / 删除 / 触发）。

## 6. 交互与快捷键

| 操作 | 快捷键 |
|---|---|
| 新建会话 | `Ctrl+N` |
| 搜索会话 | `Ctrl+K`（聚焦中栏搜索框） |
| 切换会话（上一个/下一个） | `Ctrl+Shift+[` / `]` |
| 发送 | `Enter` |
| 换行 | `Shift+Enter` |
| 终端开关 | `Ctrl+`` |
| 终端新建标签 | `Ctrl+Shift+`` |
| 终端切标签（上一个/下一个） | `Ctrl+Shift+Tab` / `Ctrl+Tab` |
| 折叠/展开中栏 | `Ctrl+B` |
| 设置 | `Ctrl+,` |

> 已实现：`Ctrl+N`、`Ctrl+Shift+[` `]`、`Ctrl+``、`Ctrl+Shift+``、`Ctrl+Tab`/`Ctrl+Shift+Tab`、`Ctrl+,`
> （解析在 `feature/shell/Shortcuts.kt`，`Shift` 改字符的键位**同时接受**移位前后两种字符）。
> 未实现：`Ctrl+K`（要跨栏传焦点）、`Ctrl+B`（`ListDetailPaneScaffold` 无对应开关）。
> 终端**获得焦点时**按键交给 PTY，Compose 的 `onPreviewKeyEvent` 收不到 —— 与 VS Code 一致。

## 7. 响应式规则

| 窗口宽度 | 行为 |
|---|---|
| ≥ 1200dp | 三栏完整（rail + list + detail） |
| 840–1200dp | 三栏，中栏略窄 |
| < 840dp | scaffold 退化单栏（list 或 detail + 返回） |
| < 640dp | rail 压到 56dp，隐藏状态点 |

## 8. 空状态与错误态

| 场景 | 呈现 |
|---|---|
| 无会话 | 图标 + "还没有会话" + 新建按钮 |
| 未选中会话 | 图标 + "选择左侧会话，或新建一个" |
| 后端未连接 | 顶部横幅（黄色）+ 重试按钮 + 查看日志 |
| 启动失败 | 整页诊断：后端地址、错误摘要、打开日志目录 |
| 加载中 | 骨架行（3–5 条）+ 进度条 |
