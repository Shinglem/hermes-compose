## 这份视觉稿的定位

> ⚠️ **本稿不严格遵循 Material 3 规范，也不是像素基准。**
> 实现**一律使用 Material 3 + Compose 原生组件**，**允许与稿子存在差异**。

- **是**：配色取向、密度、层级、组件形态、文案语气的参考。
- **不是**：1:1 复刻基准，也不是可直接照抄的 CSS。CMP 没有 CSS 的绝对定位、阴影链、
  富文本流式排版；稿子里的间距与圆角有近似值。
- **差异怎么判**：功能对等 > 原生观感 > 视觉接近。为对齐稿子去自绘控件、写死尺寸、
  覆盖 M3 默认值，都是错的方向。
- **冲突怎么解**：布局口径与交互规则以 `草案/04-ui-spec.md` 为准；视觉以 `MaterialTheme` 默认为准；
  两者都覆盖不到时才看本稿，并顺手把结论回写草案。

配色取自 **M3 baseline 浅色** token（`--primary #6750A4` 等），与 Compose 的
`MaterialTheme.colorScheme` 一一对应。实现时**不要**在代码里写这些十六进制值，
直接用 `MaterialTheme.colorScheme.*`。
