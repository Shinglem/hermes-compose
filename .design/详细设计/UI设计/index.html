是。`verify_token()` 每次都调 `load_config()`，而它内部是同步读盘再 `yaml.safe_load`：

gateway/auth.pyL88–L104
def verify_token(req):
    # 每个请求都走一次：约 0.4–1.2ms（SSD）
    cfg = load_config()          # ← open + yaml.safe_load
    secret = cfg["jwt"]["secret"]
    return jwt.decode(req.headers["authorization"], secret)

两条路径可以分开处理：

  • 热重载：保留 `load_config(force=True)`，只由 SIGHUP / 管理端触发。
  • 常规读取：进程级缓存 + mtime 校验，未变则直接返回。

gateway/config_cache.py新增
_cache: tuple[dict, float, int] | None = None

def get_config() -> dict:
    global _cache
    st = os.stat(CONFIG_PATH)      # 只 stat，不读盘
    if _cache and _cache[1:] == (st.st_mtime, st.st_size):
        return _cache[0]
    cfg = load_config()
    _cache = (cfg, st.st_mtime, st.st_size)
    return cfg
