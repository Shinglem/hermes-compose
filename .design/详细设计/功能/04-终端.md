# 04 · 终端

> 覆盖 `terminal` 域：**全局单例多标签本地 PTY**（自维护 BossTerm 裁剪版，Compose 原生渲染，
> 宿主在 `:modules:terminal`）、面板布局与拖拽、标签生命周期、焦点规则、`terminal.resize` 上报、
> 外观设置、agent 镜像视图。
>
> 关键事实：**终端不依赖后端**。PTY 完全在本地起（BossTerm 内部的 pty4j），后端只做两件事——
> 应答 server→client 的 `terminal.read`、接收 `terminal.resize`。
> 依据：[`00-功能域总览.md`](00-功能域总览.md) §2.5；决策：ADR-054（改用 Compose 原生渲染）、
> ADR-041（全局多标签、进程不复活）、ADR-042（外观设置只对新标签生效）。

---

## 1. 可见行为

| 能力 | 实现 | 说明 |
|---|---|---|
| 收起 / 展开 | ✅ | 收起 = 32dp 标题条（状态点 + 「终端」+ 运行数 + `+` + 箭头）；展开高度 = 面板 `maxHeight * heightFraction` |
| 拖拽高度 | ✅ | 上边缘 6dp 热区，向上拖变大；比例夹在 0.2–0.7 并持久化 |
| 多标签 | ✅ | 左侧 40dp 竖排 rail；切标签只换渲染的活动 tab，PTY 与文本缓冲区常驻（`BossTermSessions`），**不销毁、不重建** |
| 新建 / 关闭 | ✅ | `+` 新建（cwd 为空则用默认）；>`1` 个标签才显示关闭按钮；关最后一个自动收起 |
| `terminal.resize` 上报 | ✅ | 尺寸变化 → 延迟 150ms 等重排 → 轮询读列数（1s）→ 同会话同列数只发一次 |
| 焦点 | ✅ | `ProperTerminal(autoFocus = true)`：切/新建标签后可直接打字，不用再点一下 |
| 标签重命名 | ✅ | 双击 rail 标签 → 对话框改标题（落 `ui.terminalLayout`） |
| 重启恢复 | ⚠️ 部分 | 恢复标签列表 + cwd + 展开态 + 高度；**进程不复活**（新起 shell），**文本不回放** |
| 外观设置 | ✅ | 设置 → 终端 → 外观：字体族 / 字号 / 滚动回看行数 / 前景背景色；**即时落盘、即时生效**（无保存按钮），字体与字号对已打开标签也生效，回看行数只对**新标签**生效 |
| agent 镜像 | ✅ | 后端 agent 的后台进程输出以**只读纯文本**镜像到 `agent-<processId>` 标签 |
| 复制 / 粘贴 / 右键菜单 | ✅ | BossTerm 自带键位与右键菜单（`Ctrl+Shift+C/V`、粘贴走系统剪贴板） |
| 链接点击 / 选中加入对话 | ✅ | Ctrl+Click 打开 URL/文件路径；「选中加入对话」走 `terminalSelectedText`（无选区时回落最近 40 行） |
| 文件拖入 | ❌ | 未接线（BossTerm 有钩子，见 §7） |

## 2. 状态字段

```kotlin
// TerminalState.kt
data class TerminalLayout(               // 可持久化（ui.terminalLayout）
    val expanded: Boolean = false,
    val heightFraction: Float = 0.4f,    // 0.2–0.7
    val activeTabId: String? = null,
    val tabs: List<TerminalTabVm> = emptyList(),
)
data class TerminalTabVm(val id: String, val title: String, val cwd: String?, val kind: TerminalTabKind)
// id: "term-N" | "agent-<processId>"；cwd 在建标签时快照一次

data class TerminalPanelState(
    val layout: TerminalLayout,
    val running: Int,                    // 存活 PTY 数（1s 轮询）
    val mirrors: Map<String, String>,    // process_id → 纯文本，不持久化，单标签上限 256 KiB
) { val activeTab: TerminalTabVm?; val hasTabs: Boolean }

// TerminalSettings.kt（ui.terminalSettings，单个 JSON blob）
data class TerminalSettings(
    val fontFamily: String?, val fontSize: Float = 14f,        // 11–20
    val scrollbackLines: Int = 5000,                            // 1000–20000
    val foregroundArgb: Long = 0xFFD5DBE5, val backgroundArgb: Long = 0xFF05070B,
)
```

`TerminalViewModel` 挂在 `AppContainer`（**全局**，不属于某个会话），所以切模式、切会话都不丢标签。

## 3. 组件树

```
AppShell（会话模式底部）
└── TerminalPanel                  ← 纯 Compose 外壳（commonMain）
    ├── 标题条（32dp）
    ├── 内容区（高度按 fraction；上边缘拖拽热区）
    │   └── content(tab, Modifier)  ← 由 desktopMain 注入
    │       ├── TerminalContent → TerminalHost（ProperTerminal + 标签对账 + 列数轮询）
    │       └── MirrorTerminalView（agent 标签，纯文本）
    └── TerminalRail（左侧 40dp 竖排标签）
```

`modules/terminal`：`BossTermSessions`（private object，持有每个标签的 BossTerm tab + PTY 引擎，
与 Composition 无关）、`TerminalHost`（Compose 侧唯一入口）、
`terminalSelectedText` / `terminalTailText` / `terminalRead`（读屏出口）。
**整条链路没有 Swing 组件**：终端由 BossTerm 用 Compose Canvas + `TextMeasurer` 自绘。

## 4. 方法签名（要点）

```kotlin
// composeApp commonMain
class TerminalViewModel(...) : ViewModel() {
    val state: StateFlow<TerminalPanelState>; val settings: StateFlow<TerminalSettings>
    var readBuffer: ((start: Int?, count: Int?) -> TerminalReadPayload?)?   // desktop 注入
    var reportCols: ((sessionId: String, cols: Int) -> Unit)?
    fun updateSettings(transform: (TerminalSettings) -> TerminalSettings)
    fun toggle(); fun expand(); fun collapse(); fun setHeightFraction(f: Float)
    fun newTab(cwd: String? = null): TerminalTabVm
    fun selectTab(id: String); fun cycleTab(delta: Int); fun closeTab(id: String)
    fun onSessionChanged(next: String?); fun onColumns(cols: Int)           // resize 去重
    fun appendMirror(processId: String, chunk: String); fun closeMirror(processId: String)
}

// modules/terminal
// private object BossTermSessions：ensure / get / retain / runningCount / closeAll
fun terminalSelectedText(tabId: String?): String?                 // 选区文本
fun terminalTailText(tabId: String?, lines: Int = 200): String    // 最近 N 行（含回看）
fun terminalRead(tabId: String?, start: Int? = null, count: Int? = null): TerminalReadSnapshot?
```

契约：`terminal.read`（**server→client**，窗口应答 `{total_lines,start,end,viewport_rows,cursor_row,text}`，
无终端回空 payload）、`terminal.resize`（client→server `{session_id, cols}`，best-effort）、
事件 `agent.terminal.output` / `terminal.close`。
**会话页另有一条后台任务状态条**（`process.list` 每 5s 轮询 + `process.kill`），见
[02-对话与流式.md](02-对话与流式.md) §4「后台任务」—— 镜像标签负责"看输出"，
状态条负责"知道有哪些在跑、还能停掉"。
**不存在** `terminal.open` / `terminal.write`——PTY 是纯本地的。

环境：`TERM=xterm-256color`、`COLORTERM=truecolor`、`TERM_PROGRAM=BossTerm`（由终端内核设置）。
Windows 的默认 shell 按 **`pwsh.exe`（PowerShell 7）→ `powershell.exe`（5.1）→ `cmd.exe`** 顺序探测
（`TerminalSettings.windowsShell` 默认 `auto`；也可显式设 `pwsh` / `powershell` / `cmd`）；
显式给 `startTerminalProcess(command = ...)` 时以传入值为准（agent 镜像标签走这条）。

## 5. 空 / 错 / 载入

| 情形 | 表现 |
|---|---|
| 无标签 | 面板收起只显示标题条；点标题条或 `expand()` 自动开第一个 |
| `terminal.read` 无终端 | 回全 0 / 空文本，工具侧据此提示「没有终端」 |
| PTY 启动失败 | 仅 `Log.warn`，**界面无提示**、标签仍是空白容器（已知缺口） |
| 后端断开 | 终端照常用；只影响 `resize`（静默失败）与 `read` 应答；断线期间的镜像输出会丢（无重放） |
| 进程退出 | 守护线程 `waitFor()` → 回调 → `closeTab`；主动关闭路径不会重复触发回调 |
| agent 镜像为空 | 显示「`<title>` · 等待输出…」 |

## 6. 验收条目

- T1 开关：`` Ctrl+` `` 展开/收起；展开时没有标签会自动建一个。
- T2 多标签：新建两个标签、各自 `cd` 到不同目录、来回切换不丢输出（PTY 未重启）。
- T3 重启恢复：退出再启动 → 标签数与 cwd 恢复、展开态与高度恢复；**进程是新的**（工作区状态不保证）。
- T4 尺寸：拖拽面板高度后，后端 `sessions.cols` 跟着变；同列数不重复上报。
- T5 焦点：新建标签后直接打字能进到 shell（不需要先点一下）。
- T6 外观：改字号 → 新开标签生效；改背景色 → 容器空白区立即变。
- T7 PTY 初始尺寸：spawn 时就带合理窗口（列 ≥ 40，未布局时默认 120×30），
  resize 也钳制到同一区间 —— 否则 PowerShell 7 启动横幅按异常宽度算 `PadRight` 会直接崩（`totalWidth` 负数）。
- T7 agent 镜像：agent 跑命令时出现 `agent-<pid>` 标签并按块追加文本；进程结束标签消失。

## 7. 坑

| 坑 | 说明 |
|---|---|
| **composite build 看不见 internals** | 宿主对 `compose-ui` 是普通消费者，`bossterm-core` 的 `TerminalTextBuffer` 属 `implementation` 依赖 → 读屏能力必须在 `compose-ui/TerminalFactory.kt` 上暴露（`columns()` / `selectedText()` / `tailText()` / `snapshot()`），宿主不碰 internals |
| 注册表必须是 snapshot state | `BossTermSessions` 用 `mutableStateMapOf`；换普通 `MutableMap` 会首帧空白且之后不重组 |
| 设置必须走内存模式 | `SettingsManager` 默认落盘 `~/.bossterm/settings.json`。宿主在 `LaunchedEffect` 里 `installInMemory(bossSettings)`；另有 5 处硬编码 `user.home` 的路径已统一收敛到 `BossTermPaths.dir()`，否则会在家目录重建 `~/.bossterm` |
| 中文 IME 组合态 | 必须用 `TextFieldValue.composition` 区分"还没上屏的拼音"与"已提交"；`requestFocus` 要延后一帧（`withFrameNanos` + 短 delay），否则焦点留在终端；同一次 commit 会回调多次要去重 |
| 切输入法快捷键 | `Ctrl+Space` / `Ctrl+Shift+Space` 被微软拼音抢占，改用 `Ctrl+Alt+I` |
| 字号实时、回看行数不实时 | 字号与配色走 `installInMemory` 立即重绘；`bufferMaxLines` 在 buffer 创建时定死，只能新标签生效（ADR-042） |
| **字体名是死的，必须自己翻译** | `ProperTerminal` 只收 `sharedFont: FontFamily`，`TerminalSettings.fontName` 在渲染路径上没人读 —— 宿主必须用 `loadTerminalFont(fontName)` 把名字换成 `FontFamily`，否则设置页改字体「看起来没保存」且 Nerd 图标全是方块（系统等宽字体没有 PUA 字形）。留空时 `loadTerminalFont(null)` 回落 BossTerm 自带的 `MesloLGSNF`（2.5 MB，首次解包到 `<settings.dir>/fonts/`） |
| 列数靠轮询 | 尺寸变化后 1s 轮询 `columns()`，viewModel 侧去重后再发 `terminal.resize`；不做每帧回调 |
| 拖拽结束前不上报 | 连续 resize 只在停顿 150ms 后报一次，这是刻意的（否则每帧一次 RPC） |
| `cwd` 只快照一次 | shell 里 `cd` 不会回写标签或持久化；要跟踪需解析 OSC 7 |
| 进程退出回调要防重 | 主动 `close()` 先 `remove`，`watchExit` 只有在 `remove` 成功时才回调，否则退出两次会各调一次 |
| 镜像文本不持久化且有上限 | 上限 256 KiB，重启即丢（它只是"看一眼 agent 输出"） |
| 文件拖入未接线 | BossTerm 留了拖放钩子（`ProperTerminal` 的 drop 回调），当前没接，拖文件到终端无反应 |
| 终端与「选中加入对话」 | `terminalSelectedText` 走选区坐标解析；无选区时回落 `terminalTailText(40)` |
